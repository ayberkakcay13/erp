# ERP System

FastAPI + React + Supabase ile ERP sistemi.

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: FastAPI + SQLAlchemy
- Database: Supabase (PostgreSQL)

## Features
- ✅ Müşteri yönetimi (CRUD)
- ✅ Ürün kataloğu
- ✅ Satış yönetimi
- ✅ Fatura oluşturma

## Setup

### Backend
`ash
cd backend
python -m venv env
env\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
`

### Frontend
`ash
cd frontend
npm install
npm start
`
